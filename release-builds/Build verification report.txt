1. ROOT CAUSE ANALYSIS & PERMANENT RESOLUTION
--------------------------------------------------------------------------------
ROOT CAUSE:
In the development environment (npm run tauri:dev), the app ran through the Vite
dev server at http://localhost:5175 where external CDN stylesheets and scripts:
  - Bootstrap 5 CSS & Icons CDN (jsdelivr)
  - FontAwesome 6 Free CSS & WebFonts CDN (cdnjs)
  - Google Fonts (fonts.googleapis.com)
  - Bootstrap JS bundle with Subresource Integrity (SRI) hashes
were loaded over HTTP with local browser CORS context.

However, in the installed production desktop application (Tauri custom scheme
tauri://localhost on Linux WebKitGTK and http://tauri.localhost on Windows):
1. Subresource Integrity (SRI) & CORS Blocking:
   The <link> and <script> tags for Bootstrap CSS and JS in index.html had
   hardcoded integrity="sha384-..." attributes with crossorigin="anonymous".
   WebKitGTK evaluates SRI checks strictly against custom scheme origins. When
   the origin header or digest validation failed on tauri://localhost, WebKitGTK
   flatly blocked the stylesheet, stripping all grid and layout utilities.
2. Network Dependency on Launch:
   A dedicated kiosk desktop application frequently boots up without internet
   or with captive/firewalled connections. When external CDN stylesheets and
   Google Fonts fail to connect, all layouts collapse, icons turn into empty
   boxes, and typography reverts to generic serif/sans-serif fallbacks.
3. Missing Local Relative Base & Missing Bundle Targets:
   Vite's default base was '/', which caused absolute path resolution instead of
   clean relative path resolution for embedded assets. Additionally, "nsis" was
   missing from tauri.conf.json bundle targets.

PERMANENT FIX APPLIED:
1. Replaced all external CDN dependencies with locally bundled NPM packages:
   - 'bootstrap' (5.3.x)
   - 'bootstrap-icons' (1.11.x)
   - '@fortawesome/fontawesome-free' (6.x)
   - '@fontsource/inter', '@fontsource/orbitron', '@fontsource/outfit',
     '@fontsource/rajdhani', '@fontsource/roboto-mono'
2. Imported all styles and fonts directly into src/main.tsx in the correct cascade
   order before custom stylesheets. Vite now packages every single font file
   (.woff2/.woff) and icon asset directly into dist/assets/, providing 100% offline
   reliability with zero network latency and zero SRI/CORS failures.
3. Cleaned index.html of all brittle CDN links and SRI script tags.
4. Set base: './' in vite.config.ts to ensure robust relative path asset resolution
   across all WebView environments.
5. Configured tauri.conf.json bundle targets to include "nsis" and added complete
   NSIS installer settings for Windows cross-compilation alongside Linux "deb".
6. Updated CSP in tauri.conf.json to explicitly whitelist frame-src and media-src.
7. Created .env.production matching .env so production scripts execute cleanly.
